## 구현된 기능

### 가마솥 요리 & 배고픔 시스템

- 가마솥에서 요리를 제작하는 기능
- 요리를 제작하면 배고픔 or 체력을 채울 수 있다
- 배고픔 시스템은 아침에 일어나면 0으로 시작하고 100을 채워야 다음날 체력에 패널티가 없다
- 배고픔이 0(굶주림)이면 계산된 체력에 -30이 적용된다
- 배고픔이 1주일에 3번 0으로 하루를 마무리하면 게임 오버

### 업그레이드 시스템

- 수동 업그레이드 목록: 플레이어 이동속도, 플레이어 공격속도, 낮/밤 지속시간, 인벤토리 용량, 창고 용량
- 자동 업그레이드 목록: 제작대 아이템, 가마솥 아이템, 스폰 자원 종류, 스폰 동물 종류
- 업그레이드 시설에서 상호작용하여 패널을 열고 플레이어 관련 업그레이드를 할 수 있음
- 특정 일수가 지나면 자동 업그레이드 목록이 업그레이드 됨

## 플레이 방법

### 입력

| 입력          | 동작                                     |
| ------------- | ---------------------------------------- |
| 조이스틱      | 이동 (왼쪽 클릭 시 생성)                 |
| 액션 버튼     | 팔 휘두르기 (나무·돌·동물에 데미지)      |
| 상호작용 버튼 | 상호작용 가능한 오브젝트 근처에서 활성화 |
| 인벤토리 버튼 | 액션 버튼 위 가방 아이콘                 |
| 진행상황 버튼 | 제단 제출 현황 및 굶주림 횟수 확인       |
| 설정 버튼     | 메인 화면 복귀 (임시 구현)               |

### 게임 루프

7일마다 제단에 지정된 아이템을 제출해야 한다.

1. 자원(나무, 돌)을 채집한다.
2. 제작대에서 아이템을 제작하고 업그레이드한다.
3. 제단에서 제출 목록을 확인하고 아이템을 납부한다.
4. 밤이 되기 전에 오두막에 복귀한다.
5. 복귀 실패 또는 동물에게 사망 시 다음날로 넘어가며 인벤토리가 초기화된다.
   - 장착 중인 장비는 유지된다.
6. 21일, 42일에 자원, 동물, 아이템 종류가 늘어난다.
7. 엔딩 아이템을 제작하여 사용하면 엔딩을 볼 수 있다.

### 7일차 평가 흐름

1. 7일째 아침 도달 시 `TributeEvent.Evaluate()` 자동 호출
2. 7일째 아침 전까지 공물 납부를 완료해야 충족 처리
3. 충족 → 8일째 시작 / 미달 → 게임 오버 → 타이틀 복귀
4. 엔딩 아이템을 제작할 때까지 반복
5. 엔딩 아이템 제작 후 사용하여 엔딩 씬 입장
